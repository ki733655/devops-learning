# Linux Environment Setup & Exploration – Summary

## Objective
The goal of this task was to set up a Linux environment and become
comfortable using basic Linux commands through the terminal.

## Work Performed
- Navigated the Linux filesystem using commands like `pwd`, `ls`, and `cd`
- Created and removed directories and files using `mkdir`, `touch`, and `rm`
- Edited and viewed files using `vim` and `cat`
- Checked file permissions using `ls -l`
- Modified file permissions using `chmod`
- Changed file ownership and groups using `chown` and `groupadd`
- Monitored system resources using `top`, `df -h`, and `free -m`

## Key Learnings
- Understood the difference between root and normal users
- Learned how Linux file permissions (read, write, execute) work
- Understood ownership and group management in Linux
- Learned how to resolve permission-related errors using `sudo`
- Gained confidence working with Linux terminal

## Challenges Faced
- Encountered permission denied errors while changing file ownership
- Learned that root privileges are required for certain operations

## Outcome
After completing this task, I am confident in navigating and managing
a Linux system, which forms a strong foundation for DevOps practices.
